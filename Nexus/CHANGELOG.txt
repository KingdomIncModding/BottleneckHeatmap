Version 1.2.0:
- Foundation ModConfig Sliders: Replaced opacity dropdowns with native Foundation ModConfigElements percent sliders for Node Overlay Opacity (10%-100%), Pipe Overlay Opacity (20%-100%), and Pipe Glow Width (1.0x-2.5x).
- Vanilla Hotkey Setup: Interactive keybinding matching vanilla Controls menu. Click to rebind with any keyboard key (Escape to cancel), with full integration into Kingdom Inc's native Key Bindings menu.
- Color Palette Generator Popup: Pick any base color using live Saturation/Brightness and Hue surfaces or preset swatches, and the mod automatically computes and previews the 5 surrounding hues (Running, Starved, Clogged, Full Storage, Idle).
- Right-Click Mod Bar Shortcut: Right-click the Heatmap toggle button on the Mod Bar to open the Color Palette Generator directly from the workshop HUD.

Version 1.1.2:
- Fixed toast notification rich text parsing: directly assign TextMeshPro text on UIStatusMessage to prevent Kingdom Inc's localization regex (#highlight# syntax) from corrupting hex color tags into literal text.

Version 1.1.1:
- Replaced emoji symbols in toggle notifications with TextMeshPro color-coded text (<color=#HEX>Running</color> etc.) to prevent missing glyph boxes (□) in Kingdom Inc's retro pixel font.

Version 1.1.0:
- Added dedicated Full Storage state (vibrant Purple by default, #B042FF) exclusively for storage containers (Stockpiles and global Armories) when they reach capacity.
- Added comprehensive Foundation Mod Config settings:
  - Toggle Hotkey selector (H, B, C, F, G, M, N, P, Tab, F1-F10, etc.).
  - Color palette customization for all states: Running, Starved, Clogged, Full Storage, and Idle.
- Real-time live updating: changing colors or hotkeys in Foundation Mod Config instantly updates on-screen overlays without needing to reload.

Version 1.0.1:
- Fix Mod Bar toggle button width (160) and TextMeshPro overflow so "Heatmap: ON" / "Heatmap: OFF" displays completely without ellipsis.

Initial release 1.0.0:
- Real-time transparent visual diagnostic overlays for workshop nodes and pipes.
- Running (green), Starved (amber), Clogged (red), and Idle (slate) state detection.
- Aligned Heatmap: ON / OFF toggle button on Foundation Mod Bar.
- Instant hotkey toggle (H by default, configurable).
- Foundation Mod Config support for opacity and glow width customization.
