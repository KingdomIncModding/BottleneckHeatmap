Version 1.2.2:
- Fixed Hotkey Double Trigger: Debounced hotkey toggling and removed duplicate input checking between native InputAction callback and Update() loop to prevent simultaneous on/off double trigger.
- Unified State Colors Row Layout: Redesigned State Colors & Variations in Foundation ModConfig to match user layout: each state features a live color swatch square on the left, state label, "Pick Color" button, and dynamic variation dropdown on a single horizontal row.
- Storage vs Clogged Distinction: Storage containers (Stockpiles and Armories) are designated as Full Storage (Purple) when full; all processing nodes (Mines, Forges, Blacksmiths, Shops, Requisition Offices) and transport pipes are evaluated as Clogged (Red) when congested.

Version 1.2.1:
- Dynamic Color Variations Per State: Each bottleneck state (Running, Starved, Clogged, Full Storage, Idle) now features its own base color selector and dynamically generated surrounding hue variations (Base, Warm, Cool, Bright, Deep).
- Interactive Color Picker Wheel: Pick any color on the 2D Saturation/Brightness canvas and rainbow hue bar. The popup generates 5 surrounding hue variations on clickable cards that immediately update in real-time.
- Foundation ModConfig Integration: Full integration with Foundation's native ModConfigElements:
  - Percent sliders (via ModConfigSlider) for Node Overlay Opacity (10%-100%), Pipe Overlay Opacity (20%-100%), and Pipe Glow Width (1.0x-2.5x).
  - Dynamic dropdown options for each state that update live when new colors are selected.
- Vanilla-Style Interactive Hotkey Rebinding: Click to rebind with any keyboard key (Escape to cancel), with full integration into Kingdom Inc's native PlayerInput.RebindableKeys and Key Bindings options menu.
- Mod Bar Right-Click Shortcut: Right-click the Heatmap toggle button on the Foundation Mod Bar to open the Color Palette Wheel directly from the workshop HUD.

Version 1.1.2:
- Fixed toast notification rich text parsing: directly assign TextMeshPro text on UIStatusMessage to prevent Kingdom Inc's localization regex (#highlight# syntax) from corrupting hex color tags into literal text.

Version 1.1.1:
- Replaced emoji symbols in toggle notifications with TextMeshPro color-coded text (<color=#HEX>Running</color> etc.) to prevent missing glyph boxes (□) in Kingdom Inc's retro pixel font.

Version 1.1.0:
- Added dedicated Full Storage state (vibrant Purple by default, #B042FF) exclusively for storage containers (Stockpiles and global Armories) when they reach capacity.
- Added comprehensive Foundation Mod Config settings:
  - Toggle Hotkey selector.
  - Color palette customization for all states: Running, Starved, Clogged, Full Storage, and Idle.
- Real-time live updating: changing colors or hotkeys in Foundation Mod Config instantly updates on-screen overlays without needing to reload.

Version 1.0.1:
- Fix Mod Bar toggle button width (160) and TextMeshPro overflow so "Heatmap: ON" / "Heatmap: OFF" displays completely without ellipsis.

Initial release 1.0.0:
- Real-time transparent visual diagnostic overlays for workshop nodes and pipes.
- Running (green), Starved (amber), Clogged (red), and Idle (slate) state detection.
- Aligned Heatmap: ON / OFF toggle button on Foundation Mod Bar.
- Instant hotkey toggle (H by default, configurable).
- Foundation Mod Config support for opacity and glow width customization.
