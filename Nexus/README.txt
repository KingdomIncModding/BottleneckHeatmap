Bottleneck Heatmap 1.0.0
Author: Urakka

INSTALLATION:
1. Ensure BepInEx 5 (5.4.21+ Windows x64 Mono) is installed.
2. (Recommended) Ensure Foundation (0.5.0+) is installed for Mod Bar and Mod Config support.
3. Close Kingdom Inc if it is running.
4. Extract the contents of this archive into your Kingdom Inc root directory.
   The file should be located at:
   BepInEx/plugins/BottleneckHeatmap/BottleneckHeatmap.dll
5. Start Kingdom Inc.

USAGE:
- Click the "Heatmap: ON / OFF" toggle button on the Mod Bar.
- Or press "H" (configurable in config or Mod Config) to toggle the overlay.
- Visual state legend:
  * Green: Running / Active
  * Amber: Starved / Waiting on inputs
  * Red: Clogged / Output buffer full
  * Slate: Idle / Inactive
